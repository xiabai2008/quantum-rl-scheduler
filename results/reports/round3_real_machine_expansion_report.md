# 真机扩充实验报告（round3-B：tianyan176 低频窗口模式，2026-08-09）

> 实验脚本：`scripts/real_machine/round3_expansion_runner_v4.py`
> 原始数据：`results/real_machine/round3_expansion_20260809_v4.json`
> 关联修复：`src/api/tianyan_cqlib.py` probability 字符串解析（8.9 提交 e154441）

## 1. 背景与动机

- v2 权威真机实验（N=10×3，tianyan-287）Cohen's d=5.33 效应量异常大，受小样本限制
- 8/7 结论"176 执行成功率 15-20%"受**概率解析 bug 严重低估**（completed 但 probability 为空被判失败）
- 8.9 修复后实测：低频窗口模式下 176 真实执行成功率 **37%**（22/60）

## 2. 实验设计（预注册对齐 v2 权威）

| 项 | 值 |
|:--|:--|
| 平台 | tianyan176（287 校准中，176 为可用后端） |
| 样本 | 20 seeds × 3 策略（PPO/FCFS/SJF）= 60 次运行 |
| 真机调用 | 每 run 1 次（v2 同构），H Q1/M Q1，shots=32 |
| 模式 | 低频窗口：提交前实时探测 176 running + 探测任务确认可执行 |
| 提交 | 同步 wait_for_task 到终态（对齐 v2 `_submit_and_poll_one_task`） |

## 3. 结果

### 3.1 真机执行结果

| 指标 | 值 |
|:--|:--|
| 真机成功 | 22/60（37%） |
| 成功任务保真度 | 均值 0.7905（H 门理论 0.5，176 噪声环境合理） |
| 失败原因 | 明确 "error 终态"（平台执行失败，非解析问题） |

### 3.2 各策略（真机成功子集，探索性）

| 策略 | N | reward 均值 | 保真度均值 |
|:--|:--:|:--:|:--:|
| PPO | 10 | 1341.2 | 0.8103 |
| FCFS | 5 | 1241.1 | 0.8067 |
| SJF | 7 | 1131.4 | 0.7505 |

### 3.3 统计检验（探索性）

- PPO vs FCFS（成功子集）：Welch t=0.82，p=0.4286 **不显著**
- **样本不足**：预注册要求 N≥18/组，本实验仅 10/5/7

## 4. 结论（诚实定位）

1. **真实执行成功率修正**：8.9 修复概率解析后，176 低频模式真实成功率 **37%**（此前因 bug 误判 15-20%）。这是本次最有价值的元发现——平台能力比认知的更好，但 287 校准期间仍不足以支撑统计显著实验。
2. **扩充实验方向性**：PPO 均值最高但统计不显著（N 不足），**不宣称性能结论**。
3. **保真度数据**：22 个成功任务保真度均值 0.79，佐证 176 噪声环境（H 门 P(0) 偏斜），支撑"真机噪声对 RL 是挑战"的负向证据叙事。
4. **v2 权威口径不变**：本实验不取代 N=10 v2 权威（不同平台、成功率不同）；作为"扩充尝试的诚实记录"。
