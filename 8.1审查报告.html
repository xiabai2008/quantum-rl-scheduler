B.1 P0 根因：include_fairness_obs 默认值

# src/scheduler/env.py:178
include_fairness_obs: bool = True,  # Issue #654: 默认开启公平性观测，展示公平调度能力

# src/scheduler/env_types.py:43-47
OBS_DIM = 16  # 状态空间维度
OBS_DIM_WITH_FAIRNESS = 17  # include_fairness_obs=True 时使用

该默认值导致：

  • 环境 observation_space 默认为 Box(17,) 而非 Box(16,)
  • 35 个测试断言 (16,) != (17,) 失败
  • MARL local obs 从 19到20，global state 从 57到60
  • 16 维 PPO 模型（ppo_best_model_16dim.zip）与默认环境不兼容
  • holdout 评估维度校验失败（obs_dim=16 vs 17）
修复方案：将 include_fairness_obs 默认值改回 False。公平性观测应通过显式参数 include_fairness_obs=True 开启（如公平调度演示脚本中），而非作为默认行为。AGENTS.md 原文也写明"不影响默认 OBS_DIM=16，保持向后兼容"。

B.2 P1 根因：Mock 客户端状态大小写
