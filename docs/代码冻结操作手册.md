## 常见问题

| 问题 | 处理 |
|:--|:--|
| validate 报 CI failure | 等最新 CI 完成；本地 `--check` 不读 CI 时加 `--skip-items CODE_REPO` 仅临时排查 |
| pack 体积异常 | 正常 ~9.5MB；若 >50MB 检查是否误含 results/ 大 JSON |
| tag 推送被拒 | 用 `--force`（本地已用 -f 重打，远端需强推） |
| 测试数变了 | 冻结前一天确认 3725/3746；若中途加了测试，需同步文档 + 重生成 PPT/PDF 再 pack |
