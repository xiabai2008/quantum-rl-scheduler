- ⚠️ 退火统计不显著：p=0.9430（20seeds），效应量 d=0.41（小效应），诚实披露为探索方向

- ⚠️ 数据异常历史：旧版 6/10 seeds 的 mixed_real 与 simulation reward 完全一致，有效分叉仅 4/10（v2 已修复）

## 6. 评审答辩要点

### 6.1 核心叙事线

```
问题：量子云平台 FCFS 调度效率低（仿真验证 +20.2% 提升空间）
    ↓
创新：双向赋能（AI 调度量子 + 量子噪声反馈反哺 AI 训练环境）
    ↓
验证：N=250 统计严谨（p=7.56e-12，中效应量，Bonferroni校正，完整效应量报告）+ 真机可用性验证（315次100%成功）+ 噪声敏感性配对检验（N=25，p=2.98e-08，负向证据，诚实披露边界）
    ↓
落地：315次真机可用性验证 + 三大行业场景锚定
    ↓
价值：技术指标→业务价值换算（机时节省/科研效率/平台运营）
```

### 6.2 预期评委问题与边界声明

| 预期问题 | 边界声明 |
|---------|---------|
| "真机性能提升多少？" | 真机实验为可用性验证，性能结论由仿真支撑 |
| "退火加速显著吗？" | +6.4%，p=0.9430（20seeds，不显著），诚实披露为探索方向 |
| "商业化可行吗？" | 基于假设条件的估算，需与平台方协同验证 |
| "与 IBM/AWS 差异？" | RL 调度 + 量子噪声反馈闭环 + 开源透明 + 统计严谨 |
| "真机样本量是否足够支撑统计结论？" | 性能结论由仿真 N=250 支撑（p=7.56e-12）；噪声敏感性由 N=25 配对检验支撑（p=2.98e-08，负向证据）；真机为可用性验证（315次100%成功） |
| "量子→AI 方向证据是否充分？" | 量子→AI 为噪声敏感性闭环（N=25，p=2.98e-08，负向证据，诚实披露），非"量子提升AI性能"主张；AI→量子方向为核心（+20.2%），双向赋能逻辑为"AI调度量子 + 量子噪声反哺训练环境" |
| "p=0.9430如何解释？是否说明退火无效？" | p=0.9430（20seeds）统计不显著，Cohen's d=0.41小效应，诚实披露为探索方向；退火贡献仅+6.4%，量子-AI协同效应有限，需更大样本或优化reward设计验证 |
