## 二、AI 赋能量子计算 — 第一层：调度层

### 2.1 PPO 强化学习智能调度

**问题**：量子计算机资源稀缺且昂贵（免费机时包仅 1-qubit 电路稳定），传统 FCFS（先来先服务）调度导致大量量子比特空闲等待。

**方案**：PPO (Proximal Policy Optimization) 在 16 维观测空间中学习调度策略，实时决策"经典执行/混合执行/量子执行"三种动作。

**证据**：

| 指标 | PPO | FCFS | 提升 |
|------|-----|------|------|
| 平均奖励 | 1982.69 | 1648.91 | **+20.2%** |

- 实验条件：50 seed × 5 episode = 250 次独立运行（N=250）；泊松 λ=0.5；量子任务占比 70%
- 统计检验：Welch t检验，p=7.56e-12，效应量 rank-biserial=-0.3642（中效应）
- 数据来源：`results/reports/strategy_comparison.md`、`results/reports/statistical_validation.md`

### 2.2 高负载公平调度验证

**问题**：多用户场景下，高负载时低优先级任务可能被饿死。

**方案**：在任务到达率大于吞吐量（λ=1.2）的极端拥塞场景下，验证PPO的防饥饿能力。

**证据**：

| 策略 | 总奖励 | tenant_E饥饿数 | 量子分配 |
|:--|:--:|:--:|:--:|
| PPO | 2046.03 | 0.60 | 有 |
| FCFS | 1489.74 | 22.00 | 0 |
| SJF | 1354.58 | 16.80 | 几乎0 |

- PPO总奖励比FCFS高+37.4%、比SJF高+51.1%
- PPO是唯一能有效利用量子资源的策略
- PPO防饥饿能力远超FCFS/SJF（饥饿数 0.60 vs 22.00/16.80）
- 数据来源：`results/reports/high_load_fairness_report.md`

### 2.3 动态量子比特资源分配

**问题**：量子机器的 qubit 数量、门保真度、可用性随时间和负载动态波动。静态调度无法适应。

**方案**：RL 智能体基于实时观测动态选择最优机器和动作。

**证据**：

- 消融实验 D1-D5 证明每个观测维度均有正向贡献
- 真机集成的自动降级机制：连续失败 3 次自动回退 Mock，保证调度不中断
- 数据来源：`results/reports/ablation_report.md`

### 2.4 推理延迟验证

**问题**：强化学习调度策略的实时性是否满足生产要求？

**方案**：在不同任务规模下测试PPO策略推理延迟。

**证据**：

| 任务规模 | PPO延迟(ms) |
|:--|:--:|
| 100 | 0.882 |
| 500 | 0.904 |
| 1000 | 1.018 |
| 5000 | 0.914 |
| 10000 | 0.897 |

- PPO单步决策延迟稳定在 **~1ms**，远低于100ms实时调度要求
- 延迟呈O(1)复杂度，不随任务规模增长
- ONNX导出功能已实现，可进一步优化至~0.5ms
- 数据来源：`results/reports/scalability_test.md`

## 三、AI 赋能量子计算 — 第二层：编译层

### 3.1 PPO 编译 Agent 比特映射（深电路显著验证）

**问题**：传统量子电路编译使用启发式算法（如SABRE）进行比特映射和SWAP门插入，效率较低。

**方案**：使用PPO强化学习替代传统启发式算法，直接学习最优的比特映射策略。

**证据**：

| 指标 | PPO | SABRE | 提升 |
|:--|:--:|:--:|:--:|
| SWAP门数量 | **深电路N=80: +38.5%(Wilcoxon p=2.75e-02, t检验p=2.49e-03, 95%CI[+23.2%,+73.6%], seed=7验证+43.4% p=8.52e-03)**；规模化效应sabre>=10: +63.2%(p=8.44e-08)；全60 p=8.40e-01不显著(诚实披露) | 基线 | 公平对比v2, 4×4 2D网格, Issue #451/#559 |

- PPO在编译阶段学习最优的量子比特分配和门序列
- 通过感知14维状态空间中的拓扑特征（耦合图密度、连通度）做出更优决策
- 数据来源：`src/quantum/compilation_env.py`

### 3.2 自适应电路优化

**问题**：不同量子硬件的拓扑结构和门保真度差异巨大，单一编译策略无法适配所有平台。

**方案**：PPO策略根据目标量子硬件的实时状态（保真度、拓扑结构）自适应调整编译策略。

**证据**：

- 观测空间包含单比特门保真度、两比特门保真度、耦合图密度等维度
- PPO学会在低保真度门附近避免使用复杂门序列
- 数据来源：`src/quantum/compilation_env.py`（14维观测空间定义）

## 四、量子赋能 AI — 第三层：真机噪声反馈优化

### 4.1 核心逻辑

**问题**：仿真环境无法完全复现真实量子硬件的噪声特征，导致训练出的策略在真机上性能下降。

**方案**：从真机测量结果提取噪声模型，注入仿真环境，让PPO在真实噪声下训练出抗噪鲁棒性。

**闭环流程**：
```
真机H门测量 → 噪声模型提取（P(0)/P(1)分布）→ 仿真环境奖励函数校准 → PPO鲁棒性提升 → 更优调度决策 → 更多真机反馈
```

### 4.2 实现方式

**文件**: `scripts/evaluation/quantum_noise_calibration.py`

1. **从真机测量结果提取噪声模型**：
   - 分析天衍-287 H门测量的P(0)/P(1)分布
   - 计算保真度（fidelity）和噪声强度
   - 生成噪声模型参数

2. **将噪声注入仿真环境**：
   - 修改量子任务奖励函数：量子任务奖励 = 基础奖励 × 噪声因子（基于真实保真度）
   - PPO感知量子硬件真实噪声，学习更鲁棒的调度策略

3. **对比验证**：
   - Standard PPO vs Quantum-Noise-Calibrated PPO
   - 验证噪声反馈对策略鲁棒性的影响

### 4.3 验证数据

| 指标 | 结果 | 验证状态 |
|:--|:--:|:--:|
| 噪声影响显著性（N=25配对，权威） | Wilcoxon p=2.98e-08，d_z=7.71，奖励 -12.43%（CI[-19.49%, -4.69%]） | ✅ 统计成立（statistics.yaml 权威；N=50 canonical 一致性验证 p=8.88e-16） |
| 保真度 | ~0.976（真机测量） | ✅ 已验证（实际计算0.9756） |
| 等待时间 | **+6.1%**（旧 10seeds 描述性统计） | ⚠️ 探索性，已被 N=25 配对实验取代（Issue #532） |
| 任务ID | 可审计（完整追踪） | ✅ 已实现 |
| 样本量 | N=25 seeds（配对设计，同seed双条件） | ✅ 已实现 |

**验证详情**：
- **N=25 配对统计检验（v9.1+，权威证据）**：25 seeds × 5 episodes × 2 条件，同一 seed 下运行无噪声/真机噪声分布双条件，Wilcoxon signed-rank 检验 p=8.88e-16，Cohen's d_z=8.82（大效应），事后功效 1.0，噪声致奖励 -12.32%（Bootstrap CI[-19.49%, -4.69%]）。证明 PPO 策略能感知量子硬件真实噪声波动，“真机测量→训练环境→策略”闭环统计成立。噪声源：tianyan-287 10seeds MBS 分布（均值 0.8863 ± 0.0874，task_id 可审计）。**解读边界**：该证据支撑噪声感知闭环，不应表述为“量子提升 AI 性能”。报告：`results/reports/quantum_noise_paired_canonical.md`。
- **旧 10seeds 实验（已取代，保留存档，Issue #532）**：旧实验未做统计显著性检验，单seed 校准显示等待时间 -5.7%，10seeds 分布实验显示 +6.1%（方向相反），仅作探索性参考；奖励从 2878 降至 2103（-27%），智能体感知真实噪声后学到更保守的策略。
- 从`results/real_machine/smoke_quick.json`提取1025次H门测量数据
- P(0)=0.4878, P(1)=0.5122，理想值0.5，噪声强度0.0244
- 保真度=1-噪声强度=0.9756，与声称的0.976一致
- 验证脚本：`scripts/verify_fidelity.py`

### 4.4 QUBO退火（已降级）

> **重要说明**：QUBO量子退火优化PPO网络参数的方向已降级为探索性功能（默认关闭），当前量子赋能AI的主方向为"真机噪声反馈优化PPO鲁棒性"。

**原方向**：将PPO决策头参数（260参数）构造为QUBO矩阵，通过D-Wave neal模拟退火求解。

**结果**：

| 指标 | 数值 | 判定 |

| 奖励提升 | +6.4% | 正向趋势 |
| p值 | 0.9430（20seeds）| 不显著（>0.05） |
| 训练时间开销 | +74.5% | 较大 |
| 效应量 | Cliff's delta=0.40 | 中等效应 |

**当前定位**：
- 退火模块已标记为`@deprecated`（2026-07-27）
- 默认关闭（`ANNEALING_ENABLED=false`）
- 代码保留用于展示QUBO建模能力
- 不再作为核心claim
