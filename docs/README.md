## 修改文档前必读

1. 本索引文件 `docs/README.md` — 确认改动是否会破坏引用关系
2. 修改`technical_whitepaper.md`后需重新生成PDF：`python scripts/generate_whitepaper_pdf.py`
3. 检查 `项目记忆_给AI.md` 中的目录树是否需要同步更新
4. 新增文档后，在本索引中添加条目
5. 删除文档前，搜索所有 `.md` 文件确认无残留引用
