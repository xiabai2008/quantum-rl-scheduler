# "揭榜挂帅"量子赛道历年作品提交调研

> **用途**：团队内部参考——了解"揭榜挂帅"体系（挑战杯揭榜挂帅专项赛 → 中国青年科技创新擂台赛）历年来作品提交物的构成惯例与获奖作品形态，用于对齐本项目的提交物清单与答辩叙事。
> **调研日期**：2026-08-17
> **调研人**：AI 助手（基于公开网络信息检索）
> **权威性声明**：本赛"量子+AI 双向赋能"榜题为 2026 年首届，无严格意义的同赛道历年提交物存证；本调研为体系内可比来源（挑战杯官方平台、各高校组织通知、官方媒体报道）的综合归纳，**一切以发榜方《比赛方案》与报名系统要求为准**。

## 一、核心结论

1. "量子+AI 双向赋能"榜题（中国电信发榜）是 **2026 年首届**（第二届"中国青年科技创新揭榜挂帅擂台赛"，近 200 支队伍参赛），不存在同赛道历年提交物。
2. 但"揭榜挂帅"体系自 2021 年起即含量子赛题（第十七届挑战杯"量子安全应用"等），**提交物构成惯例高度一致**，可完整还原。
3. 历年提交物 = **报名表（盖章扫描）+ 作品压缩包（源代码 / 设计说明 / 总结报告 / 创新点 / 使用文档 + 返回结果）+ 演示材料（PPT/视频）**，与本项目 config/submission_manifest.yaml 的交付物清单几乎一一对应。
4. 往届获奖作品共同形态：**可演示原型/系统 + 真机实测证据 + 场景锚定 + 完整工程化**；本项目"平台/调度系统型"形态在体系内属主流范型。

## 三、历年提交物构成（惯例清单）

综合挑战杯申报系统、各高校组织通知与电信《比赛方案》第八点：

1. **参赛报名表**：挑战杯官网（www.tiaozhanbei.net）报名 → 系统生成报名表 → 加盖学校公章 → 扫描上传/随作品提交；所有信息须与系统填报严格一致。
2. **作品压缩包**（核心，命名规范「提报单位（学校全称）－选题名称－作品名称」）：
   - 源代码（可运行、可复现、含使用文档与安装环境说明）
   - 设计说明 / 技术方案书（PDF）
   - 总结报告（PDF）
   - 核心技术创新点说明
   - 返回结果 / 实验数据（赛题要求的实测结果）
3. **演示材料**：终审擂台赛现场答辩 PPT；部分赛题另要求演示视频。
4. **平台使用**：依托发榜方算力（本榜题 = 天衍量子云平台真机/仿真机机时）。

说明：本清单与项目 submission_manifest.yaml 交付物（CODE_REPO/CODE_ARCHIVE/WHITEPAPER/PRESENTATION/SUMMARY_REPORT/REGISTRATION_FORM/DEMO_VIDEO/实验报告/模型/原始数据）一一对应，证明清单设置符合体系惯例。

## 五、对本项目的直接启示

1. **提交物清单无需重构**：已覆盖体系惯例全部项；缺口仍为 3 件人工交付物（报名表盖章扫描版替换、总结报告填实、演示视频实拍）——这些恰是历届必查项。
2. **"返回结果"项建议**：在提交包显眼位置提供"真机实验数据 + 复现路径"说明（results/multiseed_evaluation/rewards_multiseed.json、results/real_machine/tianyan287_multiseed/multiseed_data_20260814_103336.json 等已入库，可加一行 README 指引）。
3. **答辩叙事对标**：突出「PPO 调度 +20.2%（N=250，p=7.56e-12）+ 天衍-287 真机 60/60 + 编译层 +52.1%（N=200）」完整证据链；真机数据（315 次调用 100%、N=20 v3 扩样）是区别于纯仿真队伍的核心卖点。
4. **边界诚实披露**：退火不显著（p=0.9430）、噪声负向证据（-12.43%）、真机 reward 占比低（1/96 步）等诚实披露，恰好命中评审"验证严谨性"维度（拒绝夸大要求）。
