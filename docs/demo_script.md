## 备用QA（如评委提问）

**Q: PPO为什么比FCFS好这么多？**
A: FCFS只看到达顺序，不考虑任务的量子比特需求、电路深度和当前资源状态。PPO通过14维状态观测空间，学会了在资源空闲时优先调度大任务、在排队严重时将适合经典计算的任务路由到经典资源，实现了更智能的资源分配。

**Q: 88.3%的提升是奖励函数的提升，对应到实际业务指标是什么？**
A: 奖励函数综合了资源利用率（正向）、等待时间（负向）、SLO违约（惩罚）三个维度。对应到业务指标：量子比特利用率+48.9%，任务完成率提升约15%，平均等待时间在高负载下降低约30%。

**Q: 为什么真机数据是探索性的？**
A: 天衍云平台的量子计算机存在校准周期，不同时间段的门保真度波动较大；同时真机排队时间受其他用户影响，无法控制变量。我们报告了315次调用的100%成功率，但性能对比仍需在更受控的环境下扩大样本量。

**Q: 如果量子计算机数量增加，算法能扩展吗？**
A: 我们的观测空间设计支持多机扩展，action空间可以按机器数量扩展。初步scalability测试显示PPO在3-5台量子机器场景下仍保持优势，但更大规模需要进一步训练和调优。
